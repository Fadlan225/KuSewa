# UI Branding Rules

- **Primary Color for Action Buttons**: ALWAYS use the primary yellow color `#FFC000` for all action buttons, checkboxes, focus rings, and primary interactive elements across the entire project. DO NOT use generic or default colors like emerald green (`#10B981`) or default blue for primary actions.
- **Text on Primary Buttons**: When using the primary yellow `#FFC000` background, ensure the text or icons on top of it use a dark color (e.g., `#0A2540` or `#1E293B`) for sufficient contrast, rather than white.
- **Strict Adherence**: Do NOT wait to be asked to apply these branding colors. Apply them proactively whenever adding or modifying UI components.
